# 术语表

本文档定义全项目统一术语。新增术语必须先在此登记，再在其它文档使用。

## A. 规范与编码

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| ASN.1 | Abstract Syntax Notation One | 抽象语法记法，定义数据类型与结构；本项目不解析其文本模块 |
| 编码规则 | encoding rules | 把 ASN.1 值转换为字节流的规则，如 BER、DER、CER、PER |
| BER | Basic Encoding Rules | 基本编码规则，允许确定/不定长与多种合法形式 |
| DER | Distinguished Encoding Rules | 可辨别编码规则，BER 的严格子集，要求最短形式与确定顺序 |
| CER | Canonical Encoding Rules | 规范编码规则，使用不定长与字符串分块；基线不支持 |
| PER | Packed Encoding Rules（对齐） | 紧凑编码规则，强依赖模式与约束；基线不支持 |
| UPER | Unaligned PER | 非对齐紧凑编码规则；基线不支持 |
| TLV | Tag-Length-Value | 编码的基本三元组结构 |
| 标签 | tag | 标识类型与类别；由标签类别与标签号组成 |
| 标签类别 | tag class | UNIVERSAL、APPLICATION、CONTEXT-SPECIFIC、PRIVATE |
| 标签号 | tag number | 类别内的编号；≥ 31 使用多字节形式 |
| 构造类型 | constructed | 编码层面内容由子 TLV 组成的形态；schema 侧不再用构造布尔字段，改由类型种类派生 |
| 基本类型 | primitive | 内容为原始字节的类型 |
| 类型种类 | type kind | `SIMPLE / SEQUENCE / SET / CHOICE / SEQUENCE_OF / SET_OF`，描述 schema 中类型的结构类别 |
| 标签标注方式 | tag mode | `DEFAULT / EXPLICIT / IMPLICIT`；`DEFAULT` 继承模块默认标注方式 |
| 模块默认标注方式 | module default tagging | 模块头部声明的 `EXPLICIT/IMPLICIT/AUTOMATIC TAGS`；记录在描述表头部 |
| 规范 DER 默认值 | canonical DER default | 以完整 DER TLV 字节表示的 `DEFAULT` 值；可被核心校验与重新编码比对 |
| 未使用位 | unused bits | BIT STRING 最后一个字节中不参与值的位数，合法范围 0..7 |
| 不定长 | indefinite length | 长度字段表示“直到 EOC”，仅 BER 允许 |
| EOC | End of Contents | 不定长构造类型的结束标记 `00 00` |
| 规范化 | canonicalization | 把合法但不唯一的编码转换为规则要求的唯一形式 |
| 严格模式 | strict mode | 解码时额外校验 DER 最短形式、顺序、值规范等 |
| 尾随数据 | trailing data | 顶层值结束后仍存在的未消费字节 |

## B. 对象模型与内存

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 上下文 | context | `asnber_ctx_t` 对应对象，持有分配器、错误状态、资源预算、告警记录、schema 与输出缓冲 |
| 文档 | document | `asnber_doc_t` 对应对象，持有节点树、arena 与输入所有权 |
| 节点 | node | 树中一个 TLV 的元数据与内容切片；不是独立可释放对象 |
| 模板 | schema | `asnber_schema_t` 对应对象，持有类型树、约束与默认值；由上下文分配 |
| 描述表 | schema table | `asnberc` 生成、核心加载的已编译字节数据；`uint8_t[]` 显式小端布局 |
| 预展开模块 | pre-expanded module | 由 RFC 5912 派生、已消除 `CLASS`/信息对象集的 ASN.1 模块，作为一期工具输入；当前仓库已产出 `modules/pkix/asn1/PKIX-Flattened-2009.asn1` |
| 通用 DOM | generic DOM | 不依赖模式的节点树，保留所有标签与原始切片 |
| 借用引用 | borrowed reference | 由文档持有、调用方不得释放的指针；生命周期不超过文档 |
| 零拷贝 | zero-copy | 解码时不复制输入，节点直接引用调用方缓冲 |
| arena | arena | 文档级单调分配区域，按块申请、整体释放；仅承载节点、输入副本与惰性值视图，不含 schema 与输出缓冲 |
| 上下文级分配 | context-level allocation | 随 `asnber_ctx_t` 生命周期的对象分配域，承载上下文对象、schema 与输出缓冲；与文档级 arena 分属两层 |
| 静态池 | static pool | 调用方提供的一段连续内存，包含上下文对象本身；上下文级分配与文档 arena 都只从中分配 |
| 分配器钩子 | allocator hooks | `asnber_allocator_t` 提供的 alloc/realloc/free 回调 |
| 封存 | seal | 把 runtime 构造的文档标记为只读，之后才能编码 |
| runtime 构树 | runtime tree construction | 通过 C API 创建节点并组织为文档，是主线能力 |
| 资源预算 | resource budget | 深度、节点数、输入/输出字节、告警记录数等上限 |

## C. API 与 ABI

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| C ABI | C application binary interface | 对外唯一二进制接口，只含 C 类型与函数 |
| 不透明句柄 | opaque handle | 公共头文件只声明不完整 `struct`，定义在内部 |
| `struct_size` | structure size field | 公共结构体首字段，用于跨版本布局演进 |
| 只增不改 | additive-only | 公共头文件只能新增声明/字段，不能删除或改签名 |
| 可重入 | reentrant | 不依赖全局可变状态，多个对象可独立并行 |
| 线程安全 | thread-safe | 同一对象可被多线程并发调用；本项目上下文不满足 |
| 致命错误 | fatal error | 上下文失效、只能销毁的错误，如 `ASNBER_E_INTERNAL` |
| 可恢复错误 | recoverable error | 操作失败但上下文仍可用，如数据错误、资源超限 |
| 版本宏 | version macros | `ASNBER_VERSION_MAJOR/MINOR/PATCH/STRING/ENCODED`，由 CMake 从项目版本生成；表示调用方编译时版本，运行时值由 `asnber_version` 返回 |

## D. 解码与 Schema

| 术语 | 英文 | 定义 |
| --- | --- | --- |
| 一次性解码 | one-shot decode | 一次调用把完整输入解码为文档树 |
| 增量 feed | incremental feed | 解码器对象分块接收输入、逐步推进；二期能力 |
| 事件式/SAX | event-based / SAX | 不建完整树、边读边回调；基线不提供 |
| 模式 | schema | 描述 ASN.1 类型、标签、可选性、约束与默认值的定义 |
| 模式校验 | schema validation | 在通用 DOM 上按模板类型树检查结构与约束；核心一期能力 |
| 结构化约束 | structured constraint | 挂在类型上的可多条约束，支持值域、SIZE、枚举、MAX 与大整数边界 |
| 扩展标记 | extension marker | ASN.1 `...`；建模为类型级可扩展标志与字段级扩展位置 |
| 字段路径 | field path | schema 感知解码/校验定位到字段的文本路径，如 `issuer.rdnSequence[0].type` |
| 告警 | warning | 不导致解码失败但需上报的事件；含 code、offset、depth、字段名与消息 |
| 能力位 | capability bit | `asnber_version_info_t.capabilities` 与 `asnber_has_capability()` 表达的运行期可选能力 |
| 模式编译器 | schema compiler | 把 `.asn1` 文本转换为已编译描述表的独立工具 `asnberc`；工具轨，与核心分离；输入支持自包含展平模块与多模块 `IMPORTS`（单表合并），参数化仅报 9006、展开留二期 |
| 约束求值 | constraint evaluation | 计算 SIZE、值域、可扩展性等对编码的影响；PER 依赖 |
| 定长计算 | fixed-length computation | 计算 PER 中固定部分与可变部分的位数；PER 依赖 |

## E. 阶段

| 术语 | 定义 |
| --- | --- |
| 基线 | 当前文档固定的设计，不包含未来阶段的承诺 |
| 一期 | 核心 DOM 与 BER/DER、模板机制、描述表格式、告警与能力位、`asnberc` MVP（自包含展平模块与多模块 `IMPORTS`；参数化仅诊断）、`asnber-pkix` 模块、大整数/时间/字符串/BIT STRING 只读能力 |
| 二期 | 先 PKCS 后 `asnber-cms`，两者第一版均只读；PKCS 在 0.4.0 拆为 `asnber-pkcs1/8/10/12` 四包，`asnber-pkcs` 退化为不产库的聚合包（INTERFACE 传递）；同批包含模板机制增强（跨模块增量校验与字段路径）、`asnberc` 完善 |
| 聚合包（aggregate package） | `asnber-pkcs`：不携带描述表、实现源码与库产物，也不导符号；`pkcs.h` 聚合四个实现包的公共头，`asnber::pkcs` 以 INTERFACE 依赖传递，`find_package(asnber-pkcs)` 用法保持不变 |
| 一表一 TU（one table per translation unit） | 每个描述表对应一个 `.cpp` 访问器，数组为内部链接；禁止把同模块多张表合并进单个翻译单元，否则静态链接无法按 `.o` 裁表 |
| 暂不规划 | PER/UPER（需求触发时重新评估）、CER（需求触发）；不计入任何固定阶段 |
| M0 / M1 | M0 文档基线；M1 工程骨架 |
| 独立工具轨 | `asnberc` 等独立可执行组件的交付线，不被库目标链接 |
