# ADR-0007：模式层与编译器边界

- 状态：已确认（修订，2026-11-03；决策 6 由 [ADR-0012](0012-标准模块路线与只读边界.md) 修订）

## 背景

ASN.1 的价值包含模式（schema）语义：字段角色、`OPTIONAL`/`DEFAULT`、`CHOICE`、约束与扩展标记。但 `.asn1` 文本解析与代码生成是独立且庞大的工程；若把它作为核心库的前置条件，会阻塞通用 BER/DER 解析能力。另一方面，完全不提供模式能力，调用方就拿不到字段名与约束校验。

同时，标准结构（X.509/PKIX、CMS、PKCS）属于领域知识。若把它们放进核心，会污染通用库边界，并让后续模块无法独立演进。

## 决策

1. **运行时 C ABI 构树为主线**：调用方可通过 `asnber_doc_create`、`asnber_node_create`、`asnber_node_set_*`、`asnber_doc_seal` 构造任意标签树并编码为 DER。该主线不依赖 `.asn1` 文本或代码生成。
2. **通用 DOM 为解码基础**：不启用模板也能解析、遍历、回读 BER/DER；模板感知层不改变节点布局，只附加字段名与校验结果。
3. **模板机制是核心能力**：核心提供模板描述表加载（`asnber_schema_load`）与运行时注册（`asnber_schema_add_type` / `asnber_schema_add_field`）两条入口，二者构建**同一棵类型树**；类型构造性由 `kind` 派生，标签行为由 `tag_mode` 与模块默认标注方式决定。封存后用于字段命名、结构化约束校验与 `CHOICE` 分支、`SEQUENCE OF`/`SET OF`、`OPTIONAL`、`DEFAULT`、扩展标记判定。
4. **核心只接受已编译描述表**：描述表由工具离线生成，可以是 C 源数组或二进制资源，带 `format_version`。核心运行期不解析 `.asn1` 文本，不内置任何标准结构表；表布局是 `asnberc` 与核心的唯一共享契约，见 [描述表格式](../11-描述表格式.md)。
5. **标准结构表归独立模块**：`asnber-pkix`、`asnber-cms`、`asnber-pkcs` 各自携带本模块的描述表与高层 C API；核心不感知这些模块的存在。
6. **`.asn1` 工具独立交付**：`asnberc` 负责文本解析、语义校验与描述表生成，一期交付 MVP（否则模块无法落地）。输入支持**自包含展平模块**与多模块 `IMPORTS`（A 阶段落地，单表合并，9007 已移除）；参数化仅报明确诊断（9006）。`CLASS`/`WITH SYNTAX`/信息对象集通过**预展开模块**输入，原版模块保留作参考并由 CI 校验等价性；参数化展开与直接解析留后续。（本条由 [ADR-0012](0012-标准模块路线与只读边界.md) 修订。）
7. **模块高层接口是薄封装**：`asnber_pkix_*` 一类接口只做字段定位与类型化读取，建立在模板感知的 DOM 上，不复制节点、不重复解析。
8. **不自创 schema 格式**：唯一事实来源是公开 ASN.1 模块；描述表是编译产物，不是用户可写的私有 DSL。
9. **PER/UPER 暂不规划**：没有明确需求与约束求值能力时不实现；重启条件见 [ADR-0002](0002-编码规则范围.md) 与 [ADR-0009](0009-分层与独立模块策略.md)。

## 备选方案

| 方案 | 否决理由 |
| --- | --- |
| 先做 `.asn1` 编译器再开发库 | 阻塞通用解析能力，交付周期不可控 |
| 把 `.asn1` 语法解析器嵌入核心 | 把语法前端塞进 ABI 边界，扩大体积与依赖面，嵌入式无法裁剪 |
| 核心内置标准结构表 | 核心被领域概念污染，模块无法独立演进 |
| 完全不做模板机制 | 无法提供字段名与约束校验，模块无法落地 |
| 用模板驱动解码替代通用 DOM | 未知字段无法保留，与通用解析定位冲突 |
| 外部自定义描述文件作为唯一事实来源 | 与公开 RFC 模块形成双份事实来源，易漂移 |
| 代码生成强类型结构体 | 破坏 ABI 稳定、跨语言与不透明句柄约束 |
| 模板机制推迟到二期 | `asnber-pkix` 一期无法交付，证书字段名与约束校验无法验收 |

## 后果

- 一期必须同时交付核心模板机制、`asnberc` MVP 与 `asnber-pkix`；三者缺一不可验收。
- runtime 构树 API 必须在一期冻结并测试，因为它是无模板用户与自定义结构的主要编码路径。
- 描述表格式、`format_version`、生成流程与错误码已在一期冻结，见 [描述表格式](../11-描述表格式.md) 与 [错误模型](../05-错误模型.md)；模块表由 `asnberc` 生成并随模块发布。
- 模块可以独立发布版本，但必须只依赖核心公共 ABI，不能把内部头文件作为公共依赖。
- 核心的领域词禁令由 CI 静态检查拦截，避免后续误把模块内容回填核心。
