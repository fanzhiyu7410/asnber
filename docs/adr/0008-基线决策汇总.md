## 横切承诺

1. **ABI**：从基线起按向后兼容设计；破坏性变更只能升主版本；公共头文件只增不改；生成版本宏、运行时版本、SONAME 与 CMake 包版本一致（D18）。
2. **线程**：上下文/文档的写操作非线程安全；不同对象可并行；无全局可变状态；只读节点可并发读取。
3. **许可证**：MIT；所有源文件与公共头文件带统一版权头；运行库零第三方依赖，测试与工具依赖按 D19 登记并保留其许可证。
4. **主线优先级**：runtime 构树与 BER/DER 通用 DOM 优先；核心模板机制、`asnberc` MVP 与 `asnber-pkix` 属一期；二期先做 `asnber-pkcs`（只读），后做 `asnber-cms`（只读）；模板增强、CER、PER 均不得阻塞一期。模块顺序与切片见 [ADR-0012](0012-标准模块路线与只读边界.md)。

## 备选方案

不适用。本 ADR 记录的是已确认决策；若需推翻，必须新增 ADR 并标记本 ADR 对应条目为“已取代”，不得直接修改历史结论。
